## 0. 定位与范围

### 0.1 一句话定位

> 纯 Web 前端 + 本机宿主服务：对局以**聊天室**形式呈现，人类在 PVE 中经**动作面板**出牌，观战者在纯 EVE 桌中全知围观，全程文本 LOG 由宿主**边打边写**落盘。不做 CLI，不做多客户端，不做鉴权。
> 本框架定位为**科研性质优先**——研究 LLM 能力的利用，而非游戏性优先（F-10）：LLM 思考过程对观察者透明直出（F-06，仅 EVE 观战实时开放；PVE 实时面不提供，复盘档全量留存）。

### 0.2 范围边界

| 范围内（本文档） | 范围外 |
| --- | --- |
| Web 宿主服务（形态与职责边界） | 引擎与适配器的内部实现 |

## 1. 总体架构

```
┌──────────────────────────────────────────────┐
│ 浏览器：Vue 3 + Vite 单页应用（F-05）            │
│   开桌向导页 · 对局主界面 · 桌局结束页             │
└──────────────┬───────────────────────────────┘
               │ HTTP（配置/文件查询） + WebSocket（事件流/动作）
               ▼ localhost 单机绑定，无鉴权（F-01）
┌──────────────────────────────────────────────┐
│ Web 宿主：FastAPI（F-05）                       │
│  ├─ 桌局管理器   创建/配置桌局，调引擎库            │
│  ├─ 视图流网关   玩家流 / 观战流 分发（F-02 纪律）   │
│  ├─ 动作提交网关  前端动作 → 引擎契约（02 §4）      │
│  ├─ LOG Writer  事件流 → 追加写文本文件（F-04）    │
│  └─ 静态资源托管  Vite 构建产物（单机无 CDN）        │
└──────────────┬───────────────────────────────┘
               ▼
        引擎库（02） → LLM 适配器（03）
```

**宿主是管道，不是裁判**：不改写事件、不补叙事、不自算任何规则口径——02 A-10b"事件流是唯一叙述源"在宿主层继续成立。宿主新增的只有界面文案（按钮文字、提示语）。

**前端零规则逻辑（F-09）**：围骰/全骰标注、合法动作集、飞/斋状态、积分变动等一切规则口径，全部由引擎在事件载荷中预渲染，前端只做展示。规则永远只有一份实现。

## 2. 身份与视图纪律（F-02）

| 身份 | 出现场景 | 订阅流 | 可见信息 |
| --- | --- | --- | --- |
| 观战者 | 纯 EVE 桌（桌上无人类玩家） | **观战流** | 全知：实时全员手牌 + 公开层全部事件 |
| 玩家 | PVE 桌（1 人类 + N−1 LLM） | **玩家流** | 02 §4 玩家视图：本人手牌 + 公开层；**不含 LLM 内心戏**（F-06，保留 PVE 博弈盲区） |
| 桌主 | 开桌者 | —— | 创建/配置桌局、导出文件管理（单机下与观战者/玩家同为一人） |

**硬规则**：观战流**仅在纯 EVE 桌开放**；PVE 桌一律玩家流（防止人类玩家借全知视角作弊）；桌局结束后，复盘档（含全部手牌与种子）开放查阅。

> **F-06 的口径（业主裁决，2026-11-10）**：内心戏**仅对 EVE 模式开放**——观战流实时直出聊天室与 LOG，无开关；**PVE 实时面不提供**，为人类玩家保留博弈盲区。两全实现：复盘档（桌局结束后生成，F-02）在两种模式下均全量留存 `thinking_text`，科研分析不受损——透明度让位于实时博弈，但不在数据层让步。

**视图流机制**：宿主推送统一信封 `{seq, type, payload}`；`seq` 单调递增，浏览器重连（刷新/断线）时上报 `last_seq`，宿主补发增量或全量重放（粒度在实现阶段定，N4-04）。

## 3. 页面结构

### 3.1 开桌向导页

| 区块 | 内容 |
| --- | --- |
| 模式选择 | EVE（纯 LLM，进入观战）/ PVE（1 人类席 + N−1 LLM 席，F-01：人类席恒为 1） |
| 玩家槽位 | 每槽绑定：适配器（六家之一）+ 型号轨（Pro/Flash）+ 人格包（03 §7 配置）；PVE 有一席固定为"人类" |
| 桌局参数 | 终局阈值（默认 100）、`max_rounds`、首局起叫（随机/指定）、台词限长、纠错预算、故障政策 |
| 规则开关 | 01 §12 十八项逐项开关，默认值预填（02 §6 配置体系的前端形态） |
| 提交 | 生成桌局配置 → 宿主冻结配置 → 跳转对局主界面 |

### 3.2 对局主界面（核心）

```
┌────────────────────────────────────────────────┐
│ 桌局标题 · 模式徽标（EVE 观战 / PVE） · 第 N 局      │
├────────────────────────────────┬───────────────┤
│                                │  积分榜（实时）  │
│          聊 天 流                │  飞/斋状态灯    │
│  （台词气泡 · 动作徽章 ·          │  当前叫骰       │
│    系统播报 · 开盅 · 结算 ·        │  应牌链进度     │
│    降级警示）                    │  "思考中"指示   │
├────────────────────────────────┤               │
│ 骰盅区：EVE=全员实时骰面卡          │               │
│         PVE=仅本人骰盅（点击开看）   │               │
├────────────────────────────────┴───────────────┤
│ [仅 PVE] 动作面板（合法动作集分级按钮）+ 台词输入框      │
├────────────────────────────────────────────────┤
│ ▾ 文本 LOG 抽屉（可折叠） · 导出中 → logs/xxx.log   │
└────────────────────────────────────────────────┘
```

| 区块 | 设计要点 |
| --- | --- |
| 聊天流 | 对局的主呈现（F-03）；映射表见 §4；自动滚动 + 手动上翻暂停 |
| 骰盅区 | EVE：每玩家一张卡，实时显示 5 骰面 + 围骰/全骰高亮（引擎预渲染标注，F-09）；PVE：仅本人骰盅，默认扣置、点击开看 |
| 状态栏 | 积分榜含距终局阈值的进度；应牌链进行中显示链路（谁被杀→谁反杀→×几）；某玩家决策中显示"思考中"呼吸指示 |
| 动作面板 | 引擎下发的合法动作集渲染为分级按钮：叫骰（数量/点数选择器，越界项禁用）、转斋/飞斋、开杀/跳杀（点选目标头像）、应牌三选一（开盅/反杀/投降）。与 02 C 混合接口零冲突 |
| 台词输入框 | 仅发台词，不发动作（F-03）；空发送 = 纯聊天消息 |
| LOG 抽屉 | 默认收起；展开为行式全量日志（时间戳 + 事件类型 + 内容），与聊天流同源不同形；底部常显当前导出文件路径 |
| 退出操作 | "退出并结束本桌"按钮（二次确认）——PVE 人类退出即弃局（05 G-08）；EVE 观战无此钮（关闭页面不影响桌局） |

### 3.3 桌局结束页

终局积分榜与名次（分数最小者胜）、"再来一桌"（同配置重开）、复盘档路径展示（含私密层，桌局结束后才生成，F-02）、AI 赛后评述入口位（预留，属 05，N4-05）。

## 4. 事件流 → 聊天消息映射

| 引擎事件（02 §5.1） | 聊天流渲染 |
| --- | --- |
| RoundStarted | 系统消息："第 N 局开始，A 起叫" |
| HandShaken | 不渲染（私密事件）；观战流中转为骰盅卡更新 |
| Rerolled | 系统消息："A 散骰重摇（第 2 次）" |
| BidMade | 玩家气泡：头像 + 名字 + 台词正文 + 动作徽章（"6 个 4"/"斋"/"飞"） |
| ——（适配器评测附件 `thinking_text`，经宿主转渲染，F-06） | **内心戏气泡**：作为该决策消息的**前导**插入，灰底斜体 + "内心"角标；**仅 EVE 观战流渲染**，PVE 玩家流不出现此消息类型 |
| ChallengeMade | 强调消息："D 劈 B！×2"（跳杀红色强调） |
| Responded | 玩家气泡："B 反杀！×4" / "B 投降（减半）" |
| Revealed | 开盅播报：全员骰面 + count(Y) + 判定结论 |
| RoundSettled | 结算播报：输家、倍数明细、码数、积分变动 |
| TurnDegraded | 警示消息："B 决策失败，引擎代打（最小加叫）" |
| MatchEnded | 终局播报 + 跳转结束页 |

**气泡三分纪律**：台词气泡、内心戏气泡、系统播报三者**视觉强制区分**（台词 = "玩家发言"角标；内心戏 = "内心"角标、灰底斜体）——这是 03 §3 防注入义务的 UI 面：任何台词或内心戏都不能伪装成系统消息。（PVE 下内心戏气泡不出现，纪律退化为二分，样式规范不变。）

## 5. LOG 与导出（F-04）

| 项 | 设计 |
| --- | --- |
| 内容 | 事件流的行式文本渲染（与聊天流同源；含事件类型标签与时间戳；EVE 桌内心戏以 `THOUGHT` 标签行实时直出，PVE 桌实时 LOG 不含内心戏——F-06） |
| 写入 | 宿主 LOG Writer 随事件到达**追加写** UTF-8 文本文件——实时导出的唯一实现，前端不做快照下载 |
| 命名 | `logs/match_<开始时间戳>_<mode>.log`；桌局结束另写复盘档至 `archives/`（含私密层） |
| 视角 | EVE 桌 = 全量观战视角（含实时手牌行与内心戏）；PVE 桌 = 玩家视角（公开层 + 本人手牌，不含内心戏）；复盘档仅桌局结束后生成，**两种模式均全量留存 `thinking_text`**（F-06 科研留存） |
| 抽屉 | 折叠态显示一行状态（文件路径 + 已写入行数）；展开为滚动全量视图 |

## 6. 异常与降级呈现

| 情形 | 呈现 |
| --- | --- |
| LLM 决策慢 | 状态栏"思考中"呼吸指示（谁在决策） |
| 降级代打 | 聊天警示消息 + 状态栏徽标，本局计数 |
| 引擎驳回玩家动作 | 动作面板内联错误提示（引擎返回的结构化原因，02 §4.3） |
| 断线/刷新 | WebSocket 重连 + seq 补发，整桌状态自动恢复，聊天流无缺口 |

## 7. 技术栈与宿主边界（F-05）

| 项 | 选择 | 说明 |
| --- | --- | --- |
| 宿主 | FastAPI + WebSocket | 与 Python 引擎同语言；单进程单用户假设 |
| 前端 | Vue 3 + Vite | SPA；Vite 构建产物由宿主托管 |
| 通信 | WebSocket 推事件 + HTTP 提配置/查路径 | 单机无鉴权；绑定 localhost |
| 状态恢复 | 宿主缓存全量事件流 + seq 补发 | N4-04 定粒度 |

## 8. 决策登记表（2026-11-10 界面对话）

| 编号 | 决策 | 来源 |
| --- | --- | --- |
| F-01 | 纯 Web（不做 CLI）；本机自用、单用户、无鉴权、绑定 localhost；PVE 人类席恒为 1，不考虑多客户端扩展 | 本轮 Q2 |
| F-02 | 观战流仅限纯 EVE 桌；PVE 一律玩家流；复盘档（含私密层）仅桌局结束后开放 | 本轮 Q1 |
| F-03 | 聊天室为**呈现形态**；人类输入走动作面板 + 台词框；沉浸档解析器保持二期 | 本轮 Q3 |
| F-04 | LOG 实时导出 = 宿主流式追加写文件；不做前端快照下载 | 本轮 Q4 |
| F-05 | FastAPI + WebSocket 宿主；Vue 3 + Vite 前端 | 本轮 Q5 |
| F-06 | **内心戏仅 EVE 开放**：LLM 思考文本（`thinking_text`）在 EVE 观战流实时直出聊天室与 LOG（无开关）；PVE 实时面不提供（保留博弈盲区）；复盘档两模式均全量留存供研究；仍不进任何 LLM 玩家的上下文 | 业主裁决（2026-11-10 二次修订：初裁全模式直出，改判仅 EVE） |
| F-07 | 多桌进度总览页登记二期 | 默认 |
| F-08 | 桌局结束页含复盘档入口；AI 赛后评述入口预留 | 默认 |
| F-09 | 前端零规则逻辑：一切规则口径由引擎预渲染进事件载荷 | 本轮架构主张 |
| F-10 | **科研优先原则**：本框架定位为研究 LLM 能力的利用，科研性质优先于游戏性——透明度高于博弈盲区 | 本轮裁决（F-06 之依据） |
